【PWA 离线安装包 · 使用说明】

一、完整 PWA 部署（支持"安装成 App + 离线可用"）
1. 把本文件夹里的 3 个文件（manifest.json、sw.js、icon512.png）
   连同你的 index.html 一起，放到同一个文件夹
2. 把这个文件夹部署到任何 HTTPS 服务器（如 GitHub Pages、
   自己的服务器、静态托管）
3. 用 Chrome / Edge 打开部署后的网址：
   - 地址栏右侧会出现"安装应用"图标（⊕ 安装）
   - 或菜单 → 应用 → 将此站点作为应用安装
4. 安装后：桌面出现"点名系统"图标，打开为全屏独立窗口，
   首次联网打开后自动缓存，之后断网也能用

二、不部署服务器，只想要"App 效果"（最简单）
用在线链接直接打开，然后：
- Chrome：地址栏右侧 →"安装应用"；或 菜单(⋮) → 投射/保存/共享 → 安装页面
- Edge：菜单(⋯) → 应用 → 将此站点作为应用安装
也能得到独立窗口 + 桌面图标（只是断网不可用）

三、注意
- 离线缓存会自动缓存同目录的 rollcall-data.js（你的数据文件）
- 如果改了 HTML/数据，重新打开网页就会更新缓存
